# Example: users (application-side sqlc)

This directory shows the **application** convention. It is not part of the
`packages/db` runtime — sqlc stays in the app.

```
database/
├── migrations/001_create_users.sql
├── queries/users.sql
├── sqlc/                 # generated by: sqlc generate
└── seeders/roles.sql
```

## PostgreSQL (`sqlc.yaml`)

```yaml
version: "2"
sql:
  - engine: "postgresql"
    queries: "database/queries"
    schema: "database/migrations"
    gen:
      go:
        package: "sqlc"
        out: "database/sqlc"
        sql_package: "pgx/v5"
```

App wiring:

```go
import (
    "github.com/zatrano/packages/db/postgres"
    "example.com/app/database/sqlc"
)

poolDB, err := postgres.Open(ctx, postgres.Config{DSN: os.Getenv("DATABASE_URL")})
queries := sqlc.New(poolDB.Native())
```

## MySQL

```yaml
version: "2"
sql:
  - engine: "mysql"
    queries: "database/queries"
    schema: "database/migrations"
    gen:
      go:
        package: "sqlc"
        out: "database/sqlc"
        sql_package: "database/sql"
```

```go
import "github.com/zatrano/packages/db/mysql"

d, err := mysql.Open(ctx, mysql.Config{DSN: os.Getenv("DATABASE_URL")})
queries := sqlc.New(d.Native())
```

Use a **separate** sqlc config / query dialect for MariaDB, SQLite, SQL Server, or
Oracle — do not force one dialect across all databases.

## Sample query (`database/queries/users.sql`)

```sql
-- name: GetUser :one
SELECT id, email, created_at FROM users WHERE id = $1;
```

(MySQL would use `?` placeholders — keep dialect-native SQL.)
